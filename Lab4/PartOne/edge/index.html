Grammar 
// A single call: RUN on its own, no THEN needed
RUN  RPi1.Service_A(args)

// Order-based: B runs only after A succeeds
RUN  RPi1.Service_A(args)
THEN RPi1.Service_B(args)

// Condition-based. Every IF is closed by END, ELSE is optional.
// A branch may hold several commands, and IFs may nest
IF   RPi1.Service_A() > 28 AND RPi1.Service_B() > 60
DO   RPi1.Service_C(75)
     RPi1.Service_D(40)
     IF   RPi1.Service_E() == 1
     DO   RPi1.Service_F()
     END
ELSE RPi1.Service_G()
END

Comparisons: > < >= <= == !=
Combine them with AND and OR. There are no grouping parentheses,
so nest an IF when you need to group. A condition stops as soon as
its outcome is known

Commands in a branch need no RUN. Arguments are integers, and Read_Temp
also accepts C and F for 0 and 1. Blank lines and indentation are ignored
